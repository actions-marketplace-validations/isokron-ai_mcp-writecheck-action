# Regression ledger

One row per thing that went wrong, or could, in this repository: what it was, the tests that pin it, and the commit
that fixed it. Each test named here starts with its row's ID, except where a row names an older test by its full
name. IsoKron's cross-repo ledger (`docs/LEDGER.md` in isokron-ai/tool-qa) reads this table, so keep its four
columns and write tests as `file` › `test name`. A row can say how the problem was found with a "Found by: ..."
sentence.

- `R-WC-*`: the writecheck loop worker (`loop/`, `corpus.yml`, `loop-fixture.yml`; pull request 61).
- `R-INP-*`: the dispatch inputs of the T0 worker workflows (`selftest.yml`, `dogfood-*.yml`).
