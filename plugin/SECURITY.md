# Security policy

This plugin is two Markdown Agent Skills (`mcp-write-safe-builder`, `mcp-write-safe-caller`). It has no
hooks, MCP servers or scripts, and it runs no code.

To report a problem, email **hello@isokron.ai** with "Security" in the subject, or see the full policy
in the repository root: https://github.com/isokron-ai/mcp-writecheck-action/blob/main/SECURITY.md
